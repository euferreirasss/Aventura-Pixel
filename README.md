## 🕹️ Sobre o projeto

**Aventura Pixel** é um jogo de plataformas desenvolvido com HTML, CSS e JavaScript, utilizando o Canvas para criar uma experiência interativa diretamente no navegador.

Explora o cenário, supera obstáculos, recolhe moedas e tenta chegar ao final de cada nível!

## ✨ Funcionalidades

- 🎮 Movimento do personagem.
- 🦘 Saltos para ultrapassar obstáculos.
- 🪙 Recolha de moedas e pontuação.
- 👾 Inimigos e desafios pelo caminho.
- ❤️ Sistema de vidas.
