## 🕹️ Sobre o projeto

Aventura Pixel é um jogo de plataformas desenvolvido com HTML, CSS e JavaScript. Explora o cenário, ultrapassa obstáculos, recolhe moedas e tenta chegar ao final de cada nível!

## ✨ Funcionalidades

- 🎮 Movimento do personagem.
- 🦘 Saltos e obstáculos.
- 🪙 Recolha de moedas e pontuação.
- 👾 Inimigos e desafios.
- ❤️ Sistema de vidas.
- 🏁 Objetivo final e níveis.
- 📱 Interface adaptável a diferentes ecrãs.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Canvas API
- Git e GitHub Pages

## 📂 Estrutura do projeto

## 💻 Executar localmente

Clona o repositório:

```bash
git clone https://github.com/euferreirasss/Aventura-Pixel.git
cd Aventura-Pixel
```

Abre o ficheiro `index.html` no navegador.
